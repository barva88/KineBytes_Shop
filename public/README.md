# KineBytes Shop Public Assets
Coloca tus imágenes estáticas aquí:
- `/logo.svg` o `/logo.png`: Logo principal de la tienda.
- `/favicon.ico` o `/icon.png`: Icono de pestaña del navegador.
- `/apple-icon.png`: Icono para acceso directo en pantalla de inicio de iPhone/iPad.
- `/images/`: Imágenes de banners, marcas o productos.
